Automatización de entornos: Batch, PowerShell y Winget

DevOps & Scripts

Mantener un entorno de desarrollo funcional puede convertirse rápidamente en una tarea tediosa, especialmente cuando dependes de herramientas de software muy específicas que no deben actualizarse accidentalmente y romper compatibilidades.

El problema de la actualización masiva

El gestor de paquetes winget upgrade --all es útil, pero destructivo. Si estás a mitad de un proyecto musical o de desarrollo, no quieres que Ableton Live o la terminal Warp cambien de versión repentinamente.

La solución con Regex

Diseñé un flujo híbrido utilizando scripts Batch y PowerShell. El script analiza el inventario de software actual, aplica filtros de expresiones regulares (regex) para ignorar coincidencias exactas como "Ableton Live" y "Warp", y luego actualiza sistemáticamente todo lo demás de fondo. Esto me permite mantener el sistema seguro sin comprometer las dependencias críticas de mis DAWs.
