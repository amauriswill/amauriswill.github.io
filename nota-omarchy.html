Dual-boot extremo: Reducción de particiones con Omarchy Linux

Agosto 2026 • Sistemas Operativos

Configurar un dual-boot en un entorno de producción siempre conlleva el riesgo de perder datos, pero es una necesidad cuando se desarrolla software multiplataforma.

Preparando la Lenovo T480s

Mi objetivo era instalar Omarchy Linux junto a Windows en mi ThinkPad T480s. Omarchy pedía requerimientos específicos de disco según su manual de instalación. El reto principal era lidiar con el cifrado activo.

Automatización con Diskpart

Antes de mover un solo sector, utilicé scripts en PowerShell para verificar rigurosamente el estado de BitLocker. Una vez suspendido temporalmente, programé y ejecuté comandos automáticos de Diskpart para reducir el volumen del sistema en caliente por exactamente 51200 MB (50 GB). Esta precisión garantizó un espacio seguro no asignado, permitiendo que el instalador de Omarchy Linux tomara el control de esa partición sin alterar el boot manager de Windows existente.
